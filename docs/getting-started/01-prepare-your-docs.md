# 下载桌面端并完成首次启动

如果你第一次使用 `LocalKit`，建议直接从桌面端开始。

## 下载地址

- Latest Release: <https://github.com/xiaoliuing/docs-atlas/releases/latest>
- Releases 页面: <https://github.com/xiaoliuing/docs-atlas/releases>

当前发布包通常包含这些平台：

- macOS Apple Silicon
- Windows x64
- Linux x64

具体可下载文件以后续 release 中的产物为准。

## 首次启动后会看到什么

桌面端采用**工具中心**作为默认首页。启动后先进入工具中心，再选择「文档阅读」等工具。

首次打开「文档阅读」时，会带一个默认文档仓库，指向内置的示例 `docs/` 目录。点击侧栏顶部的返回按钮可回到工具中心。

这个默认示例是为了让你直接体验完整流程：

- 左侧目录树
- 文档阅读与搜索
- 图片预览与 Mermaid 渲染
- Markdown 正文编辑、自动保存和手动保存

也就是说，打开文档阅读工具后就已经是可用状态，不需要先配一堆外部目录。

## 什么是文档仓库

文档仓库是**文档阅读工具**里的核心概念，与其他工具（如视频目录）相互独立。

一个文档仓库可以理解为：

- 一组文档源的集合
- 一套独立的阅读上下文
- 一个长期保存的本地 Markdown 入口

每个文档仓库可以拥有：

- 自己的名称与主题色
- 自己的文档源树
- 自己上次阅读的文档和滚动位置

## 桌面端编辑器能力

文档阅读工具里的正文区域支持直接编辑 Markdown：

- 修改标题和段落
- 编辑代码块、表格、引用块
- 查看 Mermaid 图表渲染效果
- 使用 `Ctrl + S` 或 `Cmd + S` 手动保存

同时还支持自动保存、切换文档前自动落盘，以及标题区域显示最后编辑时间。

## 首次启动建议先做什么

推荐按下面的顺序体验：

1. 打开工具中心，了解当前有哪些工具
2. 进入「文档阅读」，浏览示例文档目录
3. 用搜索试一下跨文档查找
4. 打开一篇文档直接修改几行内容，用快捷键保存
5. 返回工具中心，按需体验视频播放或 Agent 会话清理
6. 再开始创建你自己的文档仓库

## macOS 需要注意的点

如果当前下载包没有做 Apple 签名和 notarization，macOS 首次打开时可能会出现系统安全提示，需要手动放行。

这属于平台安全限制，不影响应用本身的本地资源读写能力。
