## 桌面端下载

- Latest Release: https://github.com/xiaoliuing/docs-atlas/releases/latest
- Releases 页面: https://github.com/xiaoliuing/docs-atlas/releases

下载时建议直接以 `Releases` 页面中的最新桌面端版本为准。

## 对当前产品的正确理解

可以把 LocalKit 理解成两层：

- **桌面端**：本地资源工具集，通过工具中心进入文档阅读、视频播放、Agent 会话清理等工具
- **Web 端**：文档阅读能力的只读延伸，负责预览、构建和发布

如果你只是想先把本机 Markdown 文档用起来，从工具中心打开「文档阅读」即可。
