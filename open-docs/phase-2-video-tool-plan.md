# Docs Atlas Desktop 工具模块与视频播放器实施方案

## 1. 背景

Docs Atlas Desktop 当前核心是本地文档阅读、搜索、收藏、最近阅读、文档仓库管理和 Markdown 编辑。下一阶段需要在不破坏阅读主流程的前提下，扩展一个独立的“工具”模块，让桌面端逐步从文档阅读器演进为本机知识与内容工作台。

本阶段首个工具是“视频播放器”。视频播放器不嵌入文档阅读页，也不复用文档目录侧栏，而是通过标题栏的 `工具` 按钮进入独立工具中心，再从工具中心进入视频播放器页面。

## 2. 产品目标

- 在标题栏左侧增加 `工具` 入口，与阅读、设置等能力平级。
- 新增工具中心页，用于承载视频播放器和未来工具入口。
- 新增视频播放器页，支持本地视频目录管理、视频浏览、播放和进度记忆。
- 保留 Web 端与桌面端现有文档能力，不为了视频工具改动文档阅读主流程。
- 为后续音频、图片、PDF、AI 问答、批处理工具预留扩展结构。

## 3. 功能边界

### 3.1 本期包含

- 标题栏 `工具` 按钮。
- 工具中心页。
- 视频播放器工具入口。
- 视频播放器独立页面。
- 添加本地视频目录，并支持目录自定义标题。
- 视频目录树、播放器舞台、播放位置记忆的页面结构设计。
- 暗色 / 亮色 / 主题色兼容设计。

### 3.2 本期不包含

- 在线视频解析。
- 视频剪辑、转码、字幕编辑。
- 云同步。
- 多端同步。
- AI 视频总结。
- 工具市场或插件系统。
- 复杂播放列表管理。
- 独立历史播放页面。

## 4. 信息架构

```text
Docs Atlas Desktop
├── 阅读
│   ├── 文档仓库
│   ├── 文档目录
│   ├── 文档正文
│   └── OUTLINE
├── 最近
├── 收藏
├── 工具
│   ├── 工具中心
│   └── 视频播放器
└── 设置
```

标题栏只负责全局级入口：

- `阅读`：回到文档阅读主界面。
- `工具`：进入工具中心。
- `搜索`：全局搜索。
- `设置`：应用级设置。

工具中心只负责工具入口，不承载具体工具的复杂操作。

工具中心内部不再放阅读、最近、收藏等阅读模块导航。阅读与工具只在标题栏做模块级切换。

视频播放器页只负责视频工具，不混入文档仓库、文档目录和 OUTLINE。

## 5. 页面设计

### 5.1 工具中心页

工具中心是一个“软件入口页”，不是卡片堆砌首页。它需要让用户快速理解当前有哪些本机工具可用。

页面结构：

- 顶部：页面标题、简短说明、工具搜索。
- 主区：工具入口列表，首个工具为视频播放器。
- 不设置阅读侧栏，不展示阅读、最近、收藏入口。

视频播放器入口展示信息：

- 名称：视频播放器。
- 描述：管理本地视频目录，记住播放进度。
- 状态：本地工具。
- 操作：打开。

### 5.2 视频播放器页

视频播放器页采用更收敛的 MVP 双区结构：

- 左侧：扁平的视频目录源分块和可折叠目录树，顶部 `+` 负责添加目录。
- 右侧：占满剩余空间的播放器舞台，只保留当前视频的必要信息。

关键交互：

- 没有视频目录时显示空状态，引导添加目录。
- 点击 `+` 后通过轻量弹窗添加目录，支持选择目录或手动粘贴路径。
- 添加目录时支持自定义 `title`，未填写时默认使用目录名。
- 每个目录源独立成块，源之间不建立嵌套关系，内部子目录默认收起。
- 添加目录后扫描常见视频格式。
- 点击树中的视频文件后加载播放器。
- 点击视频开始播放。
- 退出页面时记住播放进度。
- 再次进入时可继续播放。

## 7. 技术实施步骤

### Phase 1: 页面骨架

- 扩展桌面端主视图状态：`reader | recent | favorites | settings | tools | video-player`。
- 标题栏新增 `工具` 按钮。
- 新增 `DesktopToolHubView`。
- 新增 `DesktopVideoPlayerView`。
- 从工具中心点击视频播放器进入视频播放器页。
- 视频页支持返回工具中心和返回阅读。

### Phase 2: 视频目录源

- 增加 Tauri 目录选择。
- 支持手动输入目录路径。
- 支持填写目录自定义标题。
- 校验目录是否存在。
- 本地 SQLite 存储视频目录源。
- 目录源支持新增、删除、启用、禁用、刷新扫描。

### Phase 3: 视频扫描与列表

- 扫描常见格式：`mp4`、`m4v`、`mov`、`webm`、`mkv`、`avi`。
- 按目录结构生成视频树。
- 按文件名自然排序。
- 支持搜索视频标题。
- 保存上次播放的视频 ID 和播放位置。

### Phase 4: 播放器能力

- 使用 `vue3-video-play` 作为首版播放器。
- 支持播放、暂停、进度、音量、倍速、全屏。
- 保存播放进度。
- 再次打开同一视频时恢复播放位置。
- 切换视频或退出视频页时更新本地播放记忆。

### Phase 5: 体验补齐

- 空状态、错误态、扫描中状态。
- 主题色与暗色模式适配。
- 快捷键：空格播放暂停、左右方向键快退快进。
- 大目录性能优化。

## 8. 验收标准

- 标题栏点击 `工具` 后进入工具中心。
- 工具中心只展示工具入口，不混入阅读、最近、收藏、文档目录。
- 点击 `视频播放器` 后进入视频播放器页。
- 视频播放器页有清晰的目录源、目录树、播放器和播放位置记忆。
- 没有配置视频目录时有明确空状态。
- 添加目录时可以填写自定义标题。
- 再次打开视频工具时能定位上次播放的视频和播放位置。
- 后续实现目录扫描时，不影响文档阅读、最近、收藏、设置页面。
- 亮色、暗色和主题色下，工具中心与视频播放器视觉一致。
